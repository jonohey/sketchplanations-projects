# sketchplanations-projects

Experimental web projects — small experiments and playable demos, mostly built with Godot and other web tech.

**Browse them:** https://jonohey.github.io/sketchplanations-projects/

## Projects

| Project | Description |
|---------|-------------|
| [Echo Tower](echo-tower/) | A top-down puzzle game where statues echo your every move. Plain JS + Canvas. |
| [Ofman Core Quadrant](ofman-quadrant/) | Discover your core qualities and growth edges through the Ofman model. React + Tailwind. |
| [First Godot game (web)](first-game-test-1/) | A first Godot game exported for the web — play in the browser. |

---

*To add a new project: add an entry to the `PROJECTS` array in [`projects-data.js`](projects-data.js) — that's the only file the home page needs edited. Add a row above too, for anyone browsing on GitHub.*
